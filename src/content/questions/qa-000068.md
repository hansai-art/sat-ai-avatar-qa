## 為什麼被擋

學員把 Distilly 的 GitHub 連結交給 Hermes 安裝時，Skills Hub 掃描標示憑證存取、子程序與路徑等高風險模式。完整版含飛書、Slack、釘釘等資料收集功能，也能讀取本機 AI 記憶。這些功能超出了課程的文風練習範圍。Hermes 官方文件說明，`dangerous` 判定會阻擋 Hub 安裝，Hub 的 `--force` 仍無法覆寫。

## 方法一｜用自己的文章建立文風 Skill

挑 5 到 20 篇你自己寫的社群貼文、商品文案或 Email。在 Hermes 對話貼上下面這段，再提供文章。

```text
/learn 根據我接下來提供的文章建立 my-voice Skill。內容只用 Markdown 文字。請整理語氣與角色、用詞、句型節奏、文章結構、下判斷的方式，以及我不會用的寫法。每項附上原文例句，再做三組改寫對照。先給我看草稿再存檔。
```

建好後，用 `my-voice` 寫一篇新貼文。把不像你的地方指出來，請 Hermes 把具體修正回寫進 Skill。也可以打開 Skill 檢查內容是否只有你要的文字規則。

## 方法二｜參考 brand-voice 的整理方式

也可以請 `/learn` 參考 [brand-voice](https://github.com/affaan-m/everything-claude-code/tree/main/skills/brand-voice) 的架構，用你的文章重做中文版本，移除原有語氣與例句。先檢查草稿，再決定要不要存。

## 方法三｜確實需要完整版時，先檢查安裝內容

原回覆也提到 Distilly 專案提供獨立安裝器，適用於確實需要進階資料收集功能的人。專案文件提供 `python3 tools/install_distilly.py --host hermes --dry-run` 預覽安裝位置。執行安裝器前，先檢查它的程式與所需權限。用獨立安裝器會避開 Hermes Hub 的那次掃描，`--dry-run` 只預覽位置。確定程式碼及權限符合你的需求，再依專案文件進行，安裝後可用 `/reload-skills` 或重開工作階段，確認能找到 `/distilly`。

只需要做文風練習，前兩種方法就能開始。
