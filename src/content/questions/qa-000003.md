先用下方 Hermes 模型指南，查你已訂閱的服務支援哪種登入方式，再到該服務的帳務頁確認：

- 訂閱登入：確認方案是否允許 Hermes 使用，以及剩餘額度。
- API Key（服務密鑰）：確認是否另外按用量計費。Gemini 聊天月費與 API 計費分開。

先接通一個已有權限的模型，完成課內練習。真的遇到額度或功能限制，再考慮加買；連線設定錯誤不會因付費而修好。價格以官方方案與自己帳號顯示為準。

## 使用 ChatGPT／Codex 訂閱登入會扣 API 費用嗎？

學員問的是 Hermes 裡的 **ChatGPT or Codex Subscription** 選項。講師回覆，這條路使用 ChatGPT 帳號授權，與使用 OpenAI API Key 的計費路徑分開。要確認現在走哪條路，看 Hermes 目前選的是 Codex 訂閱登入，還是已配置 API Key 的供應商。若另用按量計費的 API 或其他工具，請分別核對該服務的用量。
