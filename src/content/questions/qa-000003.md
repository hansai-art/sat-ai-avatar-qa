先用下方 Hermes 模型指南，查你已訂閱的服務支援哪種登入方式，再到該服務的帳務頁確認：

- 訂閱登入：確認方案是否允許 Hermes 使用，以及剩餘額度。
- API Key（服務密鑰）：確認是否另外按用量計費。Gemini 聊天月費與 API 計費分開。

先接通一個已有權限的模型，完成課內練習。真的遇到額度或功能限制，再考慮加買；連線設定錯誤不會因付費而修好。價格以官方方案與自己帳號顯示為準。
