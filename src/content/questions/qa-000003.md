## 先把帳號和用途對起來
先做一張簡單清單：已買的服務、目前拿來做什麼、Hermes 提供哪種登入方式、是否另計 API 費用。不確定的欄位先留空，到官方帳務頁確認，不把「聊天網站能用」當成「任何 API 都能用」。

如果請 AI 幫你整理，提供方案名稱與官方說明即可，要求它把「已確認」和「還要查」分開列，不要交出金鑰。

以 Gemini 為例，API 的計費與額度需到對應的 [Google AI Studio 專案](https://aistudio.google.com/)確認。

## 用一件工作判斷要不要加買
先選定一個可用的模型來源，完成簡單對話，再拿自己熟悉的短筆記請它整理重點，檢查有沒有漏掉原文或補出不存在的內容。

能完成目前的練習，就先沿用。若遇到功能不支援或用量限制，記下實際限制，再比較其他登入方式、模型或方案。

連線設定錯誤先排錯，不用購買更多方案來碰運氣。

本頁不列容易過期的價格。購買前以所選服務的官方方案與你帳號實際可用的授權為準。
