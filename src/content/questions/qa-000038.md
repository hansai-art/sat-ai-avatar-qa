## 換模型之前先確認登入方式
供應商是提供 AI 服務的來源，模型是這個來源底下可選的項目。更換名稱後，仍要確認相應帳號或 API Key 可用。

Google Gemini API 與 Gemini 聊天訂閱分開。本機模型則需要另外安裝與設定執行環境，檔案、記憶體與速度需求也不同。

## 一次只換一個條件
先保留同一段測試文字，只換模型或來源，記下是否回覆。成功後再試需要讀檔或使用工具的工作，不把「能聊天」直接當成所有工作流都能跑。
