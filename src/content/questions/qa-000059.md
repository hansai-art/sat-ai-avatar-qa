先到下方 **Google API Key 管理**確認密鑰與專案，再按錯誤排查：

- 缺少 `http://` 或 `https://`：查[模型服務網址](/questions/qa-000002/)，不要在金鑰前加網址開頭。
- 429／配額限制：查[用量與重置資訊](/questions/qa-000053/)，API 可能有免費額度，不是一律先付款。

想改用課程的 ChatGPT／Codex 路徑，可以用已有權限的帳號[完成授權](/questions/qa-000051/)，再選模型測試。先釐清設定，不重複買方案碰運氣。
