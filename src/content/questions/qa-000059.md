## 先按錯誤種類排查
如果是網址缺少 `http://` 或 `https://`，先核對 API 連線網址，付費不會修好網址格式，也不要在 Key 前面加上網址開頭。

如果是 429 或配額限制，才依專案顯示的額度與重置資訊處理。API 可能有免費額度，不能一律判定要先付款。

## 想換成課程的 ChatGPT／Codex 路徑
可以先用你已有的可用帳號，在 Hermes 的供應商帳號頁完成授權，再選模型測試。不要在舊設定還不清楚時重複購買多種方案。
