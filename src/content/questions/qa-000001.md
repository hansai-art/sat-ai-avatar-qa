## 操作步驟
1. 在 BotFather 建立 bot 後，把取得的 Bot Token 填入 Hermes 的 Telegram 設定並儲存。
2. 離開 BotFather，搜尋自己設定的 bot username，確認聊天室名稱正確。
3. 按 Start 或輸入 `/start`，再傳一句簡單訊息測試。
4. 如果沒有回應，確認 Hermes 的 Gateway 已啟動，且允許的 Telegram 使用者包含你的 user ID。不要為了排錯開放所有陌生使用者。

## 還是不行怎麼辦
如果已進入自己的 bot，只是 `/help` 內容與錄影不同，先確認版本及一般對話是否可用。原留言後續也提出這個疑問，目前存檔沒有最後解決紀錄，不能據此認定設定全部完成。

回課程留言時附上版本、遮住 Token 的設定截圖、自己的 bot 是否回應一般訊息。不要把完整金鑰貼出來。
