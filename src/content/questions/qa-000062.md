回課程留言時，貼上這四項：

1. 單元與做到的步驟。
2. 預期結果與現在看到的畫面。
3. 完整錯誤文字、工具與作業系統版本。
4. 試過哪些動作，各自結果如何。

也可加入[課程 LINE 交流社群](https://line.me/R/ti/g/CNqY9D2CZB)。連結失效時回課程詢問最新入口，這個群組不會讓 LINE 直接控制 Hermes。

留言和截圖先移除 API Key、Token、驗證碼與個資。
