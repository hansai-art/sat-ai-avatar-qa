## 依這個順序排查
1. 先確認使用的提供方，再分清楚「連線網址／base URL」與「API Key」。網址和金鑰是兩種不同資料。
2. 若曾填自訂網址，對照 [Hermes 官方模型設定](https://hermes-agent.nousresearch.com/docs/user-guide/configuring-models)，查看是否少了協定、混入空白，或誤貼成金鑰。不要自行猜一個網址。
3. 若只填過金鑰、沒有改過網址，把這件事記下來，連同版本與完整錯誤一起回報，接著檢查程式實際讀到的設定。
4. 每次只改一項，再送出同一句簡單測試訊息。保留修改前後的錯誤，才能知道這次改動有沒有影響。

## 出現什麼結果，下一步會不同
若仍是缺少網址協定的錯誤，繼續查網址與設定載入。若改成明確的授權或額度錯誤，再依新的錯誤查帳號權限與用量。Gemini 聊天訂閱與 API 計費須分開確認。

回課程留言時附上版本、完整錯誤與遮住金鑰的設定畫面，讓協助者能比較你改過什麼。
