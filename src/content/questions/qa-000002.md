## 排查順序
1. 分清楚「連線網址／base URL」和「API Key」兩個欄位。金鑰不是網址。
2. 如果曾自訂網址，確認它是提供方要求的完整網址，沒有誤填成金鑰或貼入空白。
3. 如果只填過金鑰，沒有修改網址，先保留現況，不要猜一個網址填上去。還需要檢查版本與實際載入的設定。
4. 複製完整錯誤文字，附上 Hermes 版本與遮住金鑰的提供方設定畫面，回課程留言或官方問題回報區。

## 還是不行怎麼辦
原始紀錄不足以確認是哪個設定或版本造成問題。本題提供的是已核對的排查方向，並非已重現的單一修復指令。

Gemini 聊天訂閱與 Gemini API 計費是不同的服務。即使需要檢查 API 額度，也應和這個網址錯誤分開處理。
