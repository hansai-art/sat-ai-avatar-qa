## 接 LINE 前需要確認什麼
LINE Messaging API 是讓程式接收和回覆訊息的介面，Webhook 是 LINE 把訊息送到你的服務的網址。需要相應帳號、權限和可運作的接收服務，不能只把 Telegram Token 換成 LINE 帳號。

是否能由你目前的 Hermes 工具直接串接，以及訊息額度、部署與維護方式，要另外核對。

## 先沿用已驗證的工作流
保留知識庫、工作規則與成果標準，只替換手機入口。不能因為學生期待補課，就把尚未確認上架的影片寫成已提供。

[LINE 官方 Messaging API 入門](https://developers.line.biz/en/docs/messaging-api/overview/)
