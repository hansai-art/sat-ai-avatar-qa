先用 Telegram 跑通課內流程。要改接 LINE，需確認目前工具支援、帳號權限，以及接收訊息的服務。

LINE Messaging API 是程式接收和回覆訊息的介面；Webhook 是 LINE 將訊息送到你的服務的網址，不能只換 Telegram Token 就完成。

保留原本知識庫與工作規則，再評估訊息額度、部署和維護。操作影片是否已上架，請查看上課教室最新公告或回課程詢問。
