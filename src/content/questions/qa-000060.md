## 取得 Token 後要換聊天室
BotFather 建立成功會提供 Token，把它貼回 Hermes 的 Telegram Token 欄位並儲存。接著離開 BotFather，搜尋剛建立的 username，進自己的 bot 按 **Start**。

## 名稱成功不代表整條連線已完成
還要設定允許的使用者或批准配對，並確保電腦的 Hermes 與 Gateway 正在運作。最後以一般文字得到回覆作為測試。

若 BotFather 說 username 已有人使用，就換另一個名稱。不要把 Token 貼進 username 或顯示名稱欄位。
