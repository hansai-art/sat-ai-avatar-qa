三種資料不要混填：

| 欄位 | 要填的資料 |
| --- | --- |
| bot username | 機器人的帳號名稱，通常以 bot 結尾 |
| Bot Token | BotFather 提供的機器人密鑰 |
| 允許的 user ID | 你自己的數字使用者識別碼 |

儲存後離開 BotFather，進自己的 bot 按 **Start**，傳「請回覆：收到」。出現配對碼就看[批准配對](/questions/qa-000055/)；仍沒回應就查[電腦與手機連線](/questions/qa-000054/)。
