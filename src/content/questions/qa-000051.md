## 要改用 ChatGPT／Codex 訂閱時

1. 到供應商帳號設定找 **OpenAI Codex／ChatGPT or Codex Subscription**。
2. 開啟工具提供的授權網址，用自己的帳號登入並完成驗證。這個登入授權流程叫 OAuth。
3. 回 Hermes 選已授權來源的模型，開新對話傳「你好」。訂閱帳號仍需具備該服務要求的權限。

名稱與影片不同時，對照下方官方指南。官方也支援在電腦的終端機執行 `hermes model` 來選模型與登入，指令不要貼進 Hermes 聊天室。

找不到入口，就回課程留言附版本、錯誤文字與遮住密鑰的設定畫面。

## 三個課堂常見情況

- **打開就進聊天室，而且已能回覆**：講師確認該學員的對話已能進行，可以先沿用已設定的模型。若想確認是用哪個服務，查看目前選用的供應商和模型。只是看到聊天畫面時，先傳一句話測試。
- **終端機選到 API Key 的選項**：想用 ChatGPT／Codex 訂閱時，可以先離開該選項，再選 **ChatGPT or Codex Subscription**，依授權流程操作。
- **已訂閱 ChatGPT，要找綁定示範**：講師指向 **CH 1-3** 的安裝教學。影片畫面與現在的介面有差異時，可以對照下方官方指南。
