# 新手卡關改善：安裝卡關地圖與口語搜尋

2026-10-08，依 Hans 同意的新手視角檢查清單實作。沿用免費靜態網站、Pagefind、既有 62 題與問題 ID，沒有新增後端、帳號或付費服務。

## 為什麼改

新手卡住時只記得「做到哪一步」，不知道問題屬於「安裝與設定」還是「錯誤排除」，也會用自己的話搜尋。檢查時發現三個實際落差：

- 「Hermes 要錢嗎」「Hermes 安裝失敗」「裝不起來」「登不進去」等說法，補充索引找不到對的題目，結果只剩 Pagefind 全文比對，排序會被章名或其他字干擾。
- 第 1 章有 26 題，但沒有一條照操作順序走的路線，學生要自己判斷該看哪一題。
- qa-000054 第一張圖是少見的 state.db-wal 錯誤，最常見的「電腦能回、手機不回」分岔要往下捲才看得到；同一頁還有一處粗體記號直接露出 `**`。

## 學生看得到的變化

- 新增 `/install/` 安裝卡關地圖：從安裝到手機能對話分成 5 步，每一步有對應單元、說明、檢查點與該步最常見的卡關題。步驟與題號集中在 `src/data/install-steps.json`，題號寫錯或題目下架時建置會失敗。
- 首頁右欄先放安裝步驟，課程星圖移到下方；手機版排在精選 10 題之後、星圖之前，首屏仍是搜尋與前兩題。搜尋時一起收起。
- 主選單加入「課程章節」與「安裝卡關」，手機選單與側欄也有入口。第 1 章頁首、答案頁下方（「回課程對照」之前）標出這題在安裝流程第幾步。
- 搜尋框的截圖按鈕顯示文字：桌機「用截圖找」，手機「截圖」。快捷鍵提示依系統顯示 ⌘K 或 Ctrl K。截圖面板改用正面說明，仍寫明圖片不上傳、不通知老師。
- 答案頁顯示「N 則同學提問」，只算原始留言 Q 編號且至少 2 則才顯示；舊課堂存檔（CLASS）與後續排錯畫面（LIB）不另計，與 `content-source-audit.json` 的規則一致。
- 「還沒解決」的求助格式改成中文欄位：題號（qa_id）、卡在哪裡（中文選項）。用電腦開頁面時自動帶入作業系統，用手機開不帶入，因為 Hermes 裝在電腦上。說明文字不再提「工作台」。
- qa-000054 先給分岔與步驟，state.db-wal 改成最後的「少見情況」，截圖放在該段之後；修正 `**Allowed users**` 粗體。qa-000011 連到安裝卡關地圖。
- 截圖版本為「未標示」時前台不顯示這個編輯註記，只留截圖日期。62 題來源註記的「使用者提供」改為「Hans 提供」。

## 搜尋規則

- `src/data/search-synonyms.json` 新增安裝失敗、費用、沒登入、回放、bot、名稱、Mac、Windows 等口語群組。每組一次替換、長詞優先，標準詞本身也在替換清單內，避免「安裝失敗」被裡面的「裝失敗」再改一次。
- 「是、很、可以、需要、什麼、吧」等填充詞改成斷詞位置，不再黏在實詞旁產生「是費」「要費」這類沒有答案含有的雙字。「會」保留，因為「不會寫程式」需要它。
- 答案頁標題下的分類與章名不進全文索引，避免「讓工具真的接起來」「找出人們願意付錢的地方」這類章名干擾「裝不起來」「要錢」的結果。
- qa-000050 補上關鍵字「安裝失敗」。

## 驗收

- `tests/search-acceptance.test.mjs`：以正式 62 題的公開欄位建立索引，30 組新手說法的預期答案須在前三筆；同義說法排序一致；SEO 外掛安裝不得排在「裝不起來」前兩筆。這組測試在 `npm run test:unit` 與 Cloudflare 建置時都會執行，沒過就不發布。
- `tests/browser/novice-roadmap.spec.ts`：地圖每一步的題目、檢查點與連結；首頁入口與搜尋收起；手機排列順序與首屏前兩題；第 1 章與答案頁回到地圖；qa-000054 圖片位置、無「未標示」、無 `**`；提問次數與中文求助格式；6 組口語搜尋從首頁輸入後的首筆。
- `scripts/validate-output.mjs` 新增檢查：答案正文出現未轉換的 `**` 時建置失敗。
- 首頁桌機版型測試改為右欄先安裝步驟、再星圖；圖片測試改為不顯示「未標示」。

## 限制

- 安裝地圖沒有操作截圖，每一步只有文字檢查點。真實畫面要等可核對、可公開的素材。
- 地圖的步驟順序依現有答案的前後依賴整理，不代表課程影片的單元順序。
- qa-000023（課程更新年限）與 qa-000057（LINE 操作影片）仍寫「未確認」，需要 Hans 拍板後再改答案。
- 站上沒有前端分析，仍看不到零結果搜尋與「有沒有解決」的統計。若要加，需在 Cloudflare 後台開啟 Web Analytics，或另行設計匿名紀錄與告知。
- Git 歷史與舊的 Cloudflare 部署仍可能保留匿名化前的學員姓名，見 [學生入口與可讀性改版](STUDENT-REVAMP-2026-09-22.md) 的「尚未完成的驗收」。
