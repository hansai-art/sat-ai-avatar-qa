# 全部學生問答匯入

本輪逐筆讀取指定 FAQ 資料夾內 Q001 至 Q066 的問題、回覆與後續補充，修正上一版僅整理部分子問題的漏收。原始檔案不修改、不公開，學員姓名一律匿名。

## 內容對帳

- 66 筆來源紀錄全部盤點。
- 61 筆含問題或明確應用需求，拆出 104 個問題對應項目。
- 5 筆只有支持、稱讚或解決回報，保留盤點紀錄，不製造 FAQ。
- 合併相同需求後，正式 FAQ 由 22 題增為 62 題，新增 40 題。
- Q040 的 11 項複合提問全部涵蓋，直播和社群兩個需求分列，因此有 12 個對應項目。
- 同一問題的後續追問與 HTML 重複存檔不增加熱門人數。舊 CLASS 編號保留，已能對上的紀錄另標 canonicalRecord。

逐題正反向對照見 [content-source-audit.json](content-source-audit.json)。資料測試檢查每個來源子問題指向存在的 FAQ，FAQ 也能反查相同來源、日期與子問題。

## 排序與內容

首頁前十題優先解決跟課障礙：聊天室選錯、手機沒回應、模型未授權、配對批准、Gemini 網址錯誤、429 限流、費用、安裝等待、Windows 與舊電腦、使用者 ID。其餘參考不同主提問者的重複需求，不顯示推估的熱門次數。

新增內容同時涵蓋知識庫管理、自製 Skill、舊筆記排錯、公司系統串接、ROI、維護、資安、行銷、烘焙、人資、記帳、多語言學習、需求比對、教材修改、試看與直播社群。Google Drive、OneNote、LINE 有真實對應題目後才加入工具篩選。

答案依原始回覆與課程方法整理。現行模型授權、配對、使用者 ID 與 Gemini API 計費區別另核對官方文件。安裝時間只引用該學生的成功回報，不保證等待一定修好。Q065 待貼回草稿經官方文件核對後整理，不冒稱講師已發布該回覆。
