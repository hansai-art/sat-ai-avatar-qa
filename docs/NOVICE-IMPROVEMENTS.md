# 新手卡關改善

2026-09-23，接續 [新手模擬測試](NOVICE-USABILITY-AUDIT.md)。沿用免費靜態網站、Pagefind、既有 62 題與問題 ID。

## 已改動

- 搜尋保留 Pagefind 正文搜尋，新增僅含已發布標題、摘要、關鍵字與工具別名的補充索引。口語詞轉換、中文雙字比對、標題與精確關鍵字加權，讓完整句子不必每個字都出現在同一篇。明確指定的英文工具／錯誤碼仍需吻合，避免「找不到 ChatGPT」被一般的「找不到資料」文章取代。
- 所有結果及三維篩選題數取自同一候選集合。原始查詢保留在輸入框與網址；清空後恢復原排序。補充索引失效時保留 Pagefind。索引不含姓名、來源對照、編輯註記、草稿或原始筆記。
- 首頁新增「第一次來，從哪裡開始？」及「找教材與範例」，直接連既有答案，不新增教學目錄。
- 截圖辨識移到「更多篩選」，改名「截圖轉文字（非 AI 判讀）」。長截圖優先擷取錯誤行；若混有大量介面文字且只有一個明確 HTTP 錯誤碼，使用該碼搜尋。學生仍可確認、修改，不自動診斷或通知老師。
- qa-000056 補 @userinfobot 直接連結、Start、Id 數字、Allowed users 欄位及成功測試；刪除重複的名詞表格。
- qa-000054 補 Messaging → Telegram、啟用、授權與 Restart gateway 入口，以及終端機安裝者使用的指令。qa-000005 連到這段步驟。
- qa-000002 分開 Gemini 與自訂端點的處理，說清楚 Base URL 與 API Key 各填什麼，不猜測個別學員根因或服務網址。
- 重新切分思源黑體字元，避免少量新介面文字讓手機下載完整擴充字型。
