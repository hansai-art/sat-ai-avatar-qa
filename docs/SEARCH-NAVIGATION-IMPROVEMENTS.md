## 學生看得到的變化

- 首頁只呈現 10 題精選與「看全部 62 題」。完整列表移至 `/questions/`，保留常見／課程排序及分頁。
- 有搜尋字時收起首頁介紹、雙入口、推薦題與排序籤，僅保留搜尋和可展開的精簡三維篩選。提交搜尋後捲到搜尋區，讓搜尋框與結果同屏；輸入中不強制移動焦點。清空搜尋恢復原瀏覽狀態。
- `src/data/search-synonyms.json` 集中維護口語症狀與連線同義詞。只擴充檢索，不判斷原因、不產生答案；指定英文工具與錯誤碼仍須吻合。
- 零結果提供可點選的改寫查詢、完整列表與留言提問；有篩選時另提供保留關鍵字並清除篩選。
- 章節名稱同步顯示在卡片、側欄、手機導覽與篩選。保留第 1 章小節分組與固定網址。六分類改用有文字、有底色的標籤。
- 手機選單保留全部問題、章節、使用說明與回到課程。桌機與手機都連到上課教室。
- 題目末尾列出既有資料核對過的對應單元與上課教室入口。沒有新增猜測的影片時間碼或單集網址。
- 「還沒解決」才展開相關題目與可編輯、可複製的提問格式，包含題名、網址、系統／工具版本、操作步驟、錯誤訊息、試過的方法。學生須自行貼到課程留言送出。
- localStorage 只記本裝置最後閱讀的章節；首頁顯示該章與一題常見問題，可清除。移除多餘的首頁說明，保留新手與教材快捷列。
- `/questions/` 允許索引並列入 sitemap。關閉 JavaScript 可閱讀全部 62 題，首頁本來就只顯示精選 10 題。
