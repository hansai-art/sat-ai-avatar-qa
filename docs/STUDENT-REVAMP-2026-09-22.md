# 學生入口與可讀性改版

## 實際範圍

介面改版時僅有 22 題正式問答。後續重新完整盤點 Hans 指定的 FAQ 資料夾，確認有 66 筆來源與先前漏收的子問題，已增為 62 題，見 [全部匯入紀錄](FAQ-FULL-IMPORT.md)。以下測試數字記錄介面改版當時的 22 題版本。

## 優先修正

- 第 1 章原有「集中瀏覽、不分小節」例外已取消；補回已知題目的正式小節對應。所有章節共用相同選單、網址解析與索引規則。
- 正式題目統一匿名為「學員提問」，公開頁及搜尋 metadata 不再輸出姓名。來源編號、日期、原討論入口保留，私人原始資料不提交。
- 新增發布驗證，阻擋未匿名的學員姓名重新進入正式題庫。
- 以上只更新目前版本；未改寫 Git 歷史，也不宣稱搜尋引擎舊快照已刪除。

## 本輪實作範圍

兩個平行入口、六種統一分類、章節與小節分層、三維交叉篩選及題數、精簡整卡連結、結論與步驟層級、來源資訊預設收合。真實操作截圖需有可核對畫面與版本，缺少時保留文字步驟與官方連結，不製造介面。


- 首頁：搜尋優先、次要截圖辨識、兩個同等入口、固定十題與完整分頁列表。排序依原始 FAQ 編排，不顯示無根據的熱門次數。
- 章節：先選章，再依已確認小節分組。題數計算不把跨小節重複出現誤加到章節總數；沒有題目的小節與選項隱藏。
- 分類：安裝與設定、錯誤排除、帳號與費用、觀念釐清、課程範圍與資源、實際應用。列表與詳細頁讀取同一份 taxonomy。
- 篩選：章節、分類、工具可組合；每個維度的題數保留另外兩個條件計算。選中的零題條件仍保留以方便清除，其餘零題選項隱藏。舊小節分享網址繼續有效，舊用途參數遷移到分類或提示已合併。
- 答案：22 題重寫結論與第一步，補直接入口。操作名詞加白話解釋；長段落拆分，原有工作示範保留，假設仍清楚標示。
- 來源：日期、編輯核對、未確認的個別環境及原留言限制，放進最下方「來源與核對紀錄」。所有正式題目使用匿名標示。
- 外觀：四層字級，結論色塊、操作路徑、編號步驟、單則提醒、分類色點。桌機正文最多 720px，右側固定目錄；手機單欄，導覽與目錄預設收合。
- 教學截圖：未新增。FAQ 原始資料夾沒有可用圖片，舊課堂 HTML 在提供路徑已不可用；Hermes 原生畫面讀取兩次逾時，停止該路徑。不可把重畫介面當成實拍。

## 內容核對

全部 22 題逐題檢查第一句能否回答題目、第一步能否執行、直接入口是否存在、原始來源是否保留；對 Telegram、Gemini、Windows、費用、教材範圍、Notion、Heptabase、Rank Math 等另外核對現行官方文件。這是 AI 編輯檢查，沒有宣稱 Hans 逐題人工批准或學員環境已修好。

- 十個原有／新增官方文件網址以 HTTP 200 讀回；另由官方網站確認 Notion 與 Heptabase 匯出頁。
- 課程的 `sat.cool` 入口仍沿用已知網址。自動化 HTTP 請求收到 405，不能據此宣稱已驗證登入後教材，連結旁及第一步說明需要登入。
- SEO 概念題與安裝題仍分開並互相連結，既有所有問答 ID 保持不變。
- 新增後續寫作欄位與規則：`nextLinks`、`uiPath`、`caution`、`editorialNotes`。見 `FAQ-ANSWER-STANDARD.md` 與 `templates/question.md`。
