# 新手情境測試：2026-09-23

結論：網站已有可用的搜尋、章節和分類入口，但還不能判為「完全沒看過課程的人能獨立找到並解決問題」。優先問題是自然問法搜尋漏失，以及少數答案缺少操作位置。

本輪完成使用者照片 Logo 的修改，未改動搜尋規則或 FAQ。以下缺口是待修事項，不因一般瀏覽器測試通過而消失。

## 方法與限制

- AI 模擬新手，不是真人受測。每個首輪問句使用新的未登入瀏覽器環境，從首頁輸入，開啟第一筆結果，不預先指定答案網址。
- 公開站測試基準：`a99dc17ac7e82055450b0c3eea1f792fcb61f1ab`。
- 主要寬度 390×844，另以桌機操作鍵盤；Logo 另驗 360、390、430、1440px 的首頁、問題頁、章節頁。
- 10 個預先設定的問句，第一筆對題 5 個，沒有結果 4 個，第一筆不符合任務 1 個。這不是使用者成功率，也不代表 5 個問題真的修好了。
- 操作與搜尋結果是瀏覽器觀察；「新手是否懂」「是否足以解決」是內容判讀。未登入課程、安裝 Hermes、修復學員實際環境，未做真人五秒測試或真機驗收。

### 改短問法的對照

| 原本失敗或不對題 | 改用關鍵字 | 觀察 |

| 完全不會要從哪裡開始 | 從哪裡開始 | 2 題，第一筆 qa-000011 |

| 我付了ChatGPT還要付錢嗎 | ChatGPT 費用 | 2 題，第一筆 qa-000003 |

問題不是題庫沒有內容，而是要求學生自己知道怎麼刪字、換詞。目前搜尋程式只有一般 Pagefind 搜尋及特定「沒有→沒」替換，不應把它視為已能理解所有自然語句。

## 其他角色操作

- **記得自己正在上第 1 章**：首頁 → 依章節瀏覽 → 第 1 章 → 1-5 手機操控 → BotFather 題，4 次點擊可抵達答案。章節有題數，小節可跳轉，沒有點進空白小節。這條路適合已知道課程位置的人。
- **不記得章節，但知道是錢的問題**：首頁 → 依問題類型找 → 帳號與費用 → 使用 Hermes 的費用，3 次點擊到答案。六分類附白話說明，有助選擇；「安裝與設定／錯誤排除」仍可能交界，不能預設新手一定選對。
- **只想貼截圖**：上傳題庫既有 HTTP 429 原始截圖，辨識產生 505 字。直接按「用這些文字搜尋」被 200 字限制擋下，必須自己精簡。按鈕功能沒壞，但未達「貼圖就找到解法」的期待。
- **鍵盤操作**：第一個 Tab 可選「跳到主要內容」，之後能依序到搜尋框、搜尋按鈕、截圖、章節、分類與篩選。沒有在這條路徑卡住。未做完整螢幕閱讀器驗收。
- **不願讀長文／靠圖辨識**：模型選單題可點圖、放大、關閉，回到答案；使用者 ID 題表格能分清欄位，但缺少取得 ID 的操作。畫面更清楚與真正做得下去，必須分開判斷。
- **圖片首點待覆核**：一次自動化從搜尋進入後立即點圖，未取得檢視器並逾時；重新開啟答案、等待圖片載入後，放大與關閉成功。尚未定位原因，不能認定為穩定故障，也不能將此首次操作視為通過。

## 本輪 Logo 驗收

- 以使用者提供的肖像替換 Q，頁首採圓形人像，分頁圖示也使用同一張照片。
- 原照片的像素內容未改動，以 CSS 調整顯示範圍；移除公開副本的 EXIF／XMP，原附件不變。
- 正式建置、三種頁面與四個寬度的人像載入、首頁連結及無橫向溢出檢查通過。
- 發布結果另以 GitHub 提交、Cloudflare 部署與公開頁讀回確認；新手搜尋與內容缺口不列為已修復。
